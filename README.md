# RuutDev Website

Public website for RuutDev, a bilingual development studio focused on websites, business systems, and practical automation for service businesses in Florida.

## Overview

This repository contains the production website for RuutDev. The site presents RuutDev's services, selected work, process, company information, and contact flow in both English and Spanish.

## Stack

- HTML, CSS, and JavaScript
- Node.js 22
- Vercel serverless API functions
- Supabase
- Stripe

## Development

Install dependencies and start the local Vercel development environment:

```bash
npm install
npm run dev
```

## Quality Checks

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
